# meetwell
Meetwell is a visual tool that finds the best time to talk to someone in a different timezone. 

Add anyone's city, and it draws their day as a strip of color: gold for daylight, dusty rose for dawn and dusk, indigo for night. Stack a few people together, and the hours where everyone's awake light up on their own. Drag across the strip to test a time and see it land on each person's clock at once, or let the tool suggest windows that avoid waking anyone at 3am.

Built for the moment before you send "does 6pm work?" — whether that's a call with your parents across the world or a meeting with a client three timezones over.
